# Mixr

Volume and device control for Windows. A personal fork of [EarTrumpet](https://github.com/File-New-Project/EarTrumpet), reworked for setups with lots of audio devices.

## Goals

- Hide or pin output devices so the flyout only shows the ones you use
- Rename devices to friendly names
- Collapse idle devices
- One click profiles that switch default devices and app routing together
- Drag an app onto a device to move its audio
